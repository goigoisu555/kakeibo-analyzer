# Kakeibo Analyzer

CSV形式の家計簿データを読み込み、支出を分析するPythonアプリです。  
カテゴリ別・月別・日別の支出をランキング形式で表示できます。

---

## 使用技術
- Python

## 機能
- カテゴリ別支出ランキング（合計・平均）
- 月別支出ランキング（合計・平均）
- 日別支出ランキング（合計・平均）
- 最も支出の多いカテゴリの表示

---

## 使い方

### ① CSVファイルを用意
以下の形式でデータを作成します。

日付,カテゴリ,金額

例：
2026-03-01,食費,1200
2026-03-01,交通費,500
2026-03-02,食費,800

### ② プログラムを実行

ファイル名を入力すると分析結果が表示されます。

---
カテゴリ別（合計）

1位 娯楽 | 合計: 5700円 | 平均: 1900.0円
2位 食費 | 合計: 5500円 | 平均: 1100.0円
3位 交通費 | 合計: 1800円 | 平均: 600.0円
